# Seagate Open Source Compliance

## Overview

This repository provides a centralized location for open source software (OSS) license compliance documentation associated with Seagate products.

Seagate products may incorporate open source software that is subject to licensing requirements such as attribution, copyright notices, license text distribution, source-code availability, modification notices, or other obligations.

This repository is intended to make the required compliance documentation available in a consistent and easily discoverable location.

## Repository Structure

Compliance documentation must be organized using the **customer-facing brand or product name**.

Create a directory at the root of this repository for each Seagate product that requires OSS compliance documentation.

For example:

```text
Seagate-OpenSourceCompliance/
|
|-- FireCuda-Forge/
|   `-- [license compliance documents]
|
`-- README.md
```
